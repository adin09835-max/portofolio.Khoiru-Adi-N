## Run Locally

1. Open this folder in **VS Code**.
2. Install the **Live Server** extension (if not already installed).
3. Right-click `index.html` → **Open with Live Server**.
4. The site opens in your browser and auto-refreshes as you edit files.

No `npm install` or build step is required — this is a fully static site.

## Deployment (GitHub Pages)

```bash
git init
git add .
git commit -m "Initial commit: portfolio website"
git branch -M main
git remote add origin https://github.com/adin09835-max/YOUR-REPO-NAME.git
git push -u origin main
```

Then on GitHub:

1. Go to your repository → **Settings** → **Pages**.
2. Under **Branch**, select `main` and folder `/ (root)`.
3. Click **Save**.
4. Your site will be published at:
   `https://adin09835-max.github.io/YOUR-REPO-NAME/`
